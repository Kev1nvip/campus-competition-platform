## 三、仍存在的 Bug

### 🔴 Bug-1（P1）：学生端"获奖记录"无法显示

**根本原因**：`GET /api/v1/award/my` 接口用 `submitter_id = 当前用户 ID` 查询，但获奖记录是由老师在**教师端**提交的（`submitter_id = 老师 ID`），学生查不到自己参与的获奖记录。

**应该的逻辑**：学生端"我的获奖记录"应通过**报名记录关联**查询：
- 个人赛：`individual_signup.student_id = 当前用户` → 找到 `individual_signup.id` → 查 `award_record.biz_id = 该 ID AND biz_type = 'INDIVIDUAL'`
- 团队赛：`team_member.student_id = 当前用户` → 找到 `team_id` → 找到 `team_signup.id` → 查 `award_record.biz_id = 该 ID AND biz_type = 'TEAM'`

**需修复文件：**
- `backend/controller/AwardController.java`：新增 `GET /award/my/student` 接口，通过报名关联查当前学生相关的获奖
- `frontend/views/StudentProfile.vue`：改调新接口

### ⚠️ 缺口-1：RabbitMQ 未实现（影响课程验收）

**现状**：`docker-compose.yml` 有 RabbitMQ 容器，`application.yml` 有配置，但后端代码里完全没有 `RabbitTemplate`/`@RabbitListener`，消息通知是**同步写库**而非通过 MQ 异步推送。

PRD 要求：`RabbitMQ异步处理消息推送，不阻塞核心业务`

课程验收要求：`□ RabbitMQ异步消息已实现（通知推送）`

**影响**：功能上通知可以正常收发，但技术架构不符合 PRD 和课程要求。

## 五、已完整实现的功能列表

**用户模块：** 统一登录分流、注册（角色校验）、个人信息编辑、用户禁用/启用、教师列表（无需登录）

**竞赛模块：** 发布（完整字段含时间）、列表筛选分页、详情、状态每分钟自动流转、下架/恢复、Redis 名额初始化

**个人赛流程：** 选老师报名 → 通知老师 → 老师同意指导（通知学生）→ 学生提交管理员审核（通知管理员）→ 管理员审核（通知学生/老师）

**团队赛流程：** 创建队伍 → 申请老师带队（通知老师）→ 老师同意（通知队长）→ 邀请/招募队友（通知被邀请人）→ 队友接受（通知队长）→ 队长提交管理员审核（通知管理员）→ 管理员审核

**招募帖：** 老师发布/关闭、学生申请加入、老师处理申请；队大厅展示招募中队伍

**审核：** 管理员个人赛/团队赛报名审核页（含驳回原因）、获奖审核页

**获奖记录：** 提交（含证书图片上传）、管理员弹窗预览证书、管理员审核（通知提交人）

**消息通知：** 19 处业务写入，前端铃铛 30 秒轮询，通知面板支持直接操作同意/拒绝（指导申请、带队申请、入队邀请、TEAM_GUIDE）

**数据统计：** 用户/竞赛/获奖三类统计，枚举值正确

**AI 推荐：** LangChain4j + PGVector RAG 链路完整实现
